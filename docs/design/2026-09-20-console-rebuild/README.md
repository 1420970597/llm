## 一、为什么重新设计

当前产品的问题有可复现证据：评估默认进入维度管理，报告与创建都共享同一 URL；“结果与报告”刷新回到“维度管理”。清洗同时承载执行、历史、报告、关键词、批量导入和规则。SFT、GRPO 和思维标准这些核心业务又被放入任务详情的“进阶能力”。

这些问题的根因是页面没有按对象和用户工作划分。新方案用独立列表、详情、编辑、运行与报告承载它们，避免继续增加一个万能详情页的面板数量。

调研实际阅读了原始业务需求和前后端实现，并访问 Label Studio、Argilla、Langfuse、Dify 官方文档，以及 Carbon、NN/g、W3C 的相关说明。来源、借鉴点、未照搬的部分和仍需实访的假设均见 [调研报告](01-research.md)。没有把桌面研究包装为用户访谈。

![全站信息架构：六个业务入口与独立管理区](assets/information-architecture.svg)

## 三、关键页面与点击说明

### G02 工作台：从待办直接进入处理对象

![工作台原型](assets/screens/G02.png)

“创建生产任务”进入三步向导；“处理待复查样本”进入带筛选的样本列表；“查看失败原因”直接到运行详情；最近导出进入文件详情。工作台不展开所有阶段表单。

### T02 创建任务：目标、结构、提交分开决策

![任务创建原型](assets/screens/T02.png)

SFT 生成思维链与答案；切换 GRPO 后显示奖励档位。n/m/x 在第二步始终可控，并实时显示乘积。管理员连接参数不平铺在业务创建页。下一步校验当前步骤，上一步保留草稿；第三步说明规模与环境就绪。

### T04 领域与方向：独立编辑和明确确认

![结构确认原型](assets/screens/T04.png)

左侧选择领域，右侧修改名称和方向；新增/移除只改草稿，“保存结构”持久保存，“确认结构并继续”检查未保存和结构合法性后进入思维标准。结构生成和用户确认是不同动作。

### T06 思维标准：核心能力有完整编辑页

![思维标准编辑原型](assets/screens/T06.png)

逐步编辑标题和检查点，支持重排与增删；提交时填写变更说明并生成新版本。样本引用的旧版本使用只读地址，修改当前标准不会把历史证据替换掉。

### D03–04 样本：列表用于查找，详情用于判断

![样本浏览原型](assets/screens/D03.png)

筛选状态后列表与计数同步，URL 保存筛选；勾选后才出现批量导出，明确只选当前页。点击问题进入完整内容、质量证据与来源，不在列表铺开整段长链文本。

![单条样本原型](assets/screens/D04.png)

### E01 / E06 评估：运行与报告有自己的地址

![评估运行列表原型](assets/screens/E01.png)

评估首页直接展示运行；“新建评估”进入独立表单；“维度库”跳到资源库。运行详情、逐条评分、评分证据、完整报告各自可定位，刷新不退回配置页。

![评估报告原型](assets/screens/E06.png)

报告标明样本覆盖、评分完成度、量表和分歧阈值；分数有服务端计算契约。未完成运行不显示最终质量结论。点击分歧项到单条证据，查看两个裁判的理由，再决定是否修改标准。

### C01 / C05 清洗：执行、配置和人工判断分开

![清洗运行列表原型](assets/screens/C01.png)

![单条清洗复查原型](assets/screens/C05.png)

新建清洗只选择数据、阶段和规则；关键词和规则在独立资源页维护。命中详情显示上下文，用户填写理由后保留或隔离，返回列表能看到处置结果。预览、人工复查与可撤销隔离是明确的后端增量。

### D10 / D11 GRPO：下游继续保持训练类型

![GRPO 单条样本原型](assets/screens/D10.png)

![GRPO 导出原型](assets/screens/D11.png)

GRPO 样本展示教师提示词和奖励判据，导出使用对应字段，不掉回 SFT/Alpaca。当前后端尚未完整适配教师提示词的独立评分与清洗时，界面保留 GRPO 上下文并说明不可启动的原因。

### R01 / A01 公共配置独立维护

![资源库原型](assets/screens/R01.png)

资源库分生成模板、指令、维度、清洗规则、关键词和字段映射。每类都有列表、详情及新增/编辑地址；管理员拥有系统连接与审计页。现有后端需要管理员的资源，原型成员模式也不能绕过去编辑。

## 四、实现顺序与设计边界

先落地路由和页面拆分，复用现有后端；再实现版本快照、精确导出范围、清洗复查与持久编排。自动执行不能通过浏览器串接几个请求伪装成后台能力。暂无法可靠估算的费用和 ETA，明确显示未知。

本原型提供真实的本地交互和演示文件下载，数据均为虚构示例。真实模型调用、数据库写入、后台运行、服务端权限与完整无障碍验收仍属于正式实施工作。验证报告说明已经检查了什么、尚未实现什么。
