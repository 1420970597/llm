# 逐页、逐元素交互规格

原型页面 ID 与 `prototype/catalog.js` 共用，目录提供 64 个主要页面示例，另有 8 类新增表单、编辑模式、三步向导和异常状态。下面的路由用业务 ID 占位，原型使用 dataset/task=24、eval=36、cleaning=18 作为演示，GRPO 资产使用 dataset=25。

标记：**现有**＝找到对应后端能力；**组合**＝能基于现有接口与前端路由重组，仍需实现；**增量**＝需要新增后端契约。这里描述目标产品行为；原型的可操作范围与限制见最后一节和验证报告。

## 0. 所有页面继承的控件契约

| 元素 | 点击 / 操作后的效果 | 返回与状态 | 实现约束 |
|---|---|---|---|
| Logo | 跳 `/home` | 不触发业务修改 | 原生链接 |
| 一级菜单 | 进入对应列表或首页 | 高亮当前对象域；浏览器后退可返回 | 无多余“中转欢迎页” |
| 面包屑 | 跳当前对象的父级 | 详情返回列表保留筛选 | 根据路由字典派生 |
| 头像 | 进入 `/account` | 独立于任务上下文 | 不混入任务筛选 |
| 通知 | 进入 `/notifications` | 未读计数来自通知记录；无数据时不造数字 | 持久通知为增量 |
| 帮助 | 进入 `/help` | 业务页面的定向帮助可带文章 ID | 静态文章可先落地 |
| 搜索 | 输入后 300ms 查询；Enter 立即查询 | query 保存关键词；切换关键词回到第 1 页 | 后端分页/检索待补处需明确数据范围 |
| 筛选 | 即时更新列表与结果数 | query 保存；“清除筛选”清空过滤、保留对象 | 不使用共享的全局选中任务 |
| 列排序 | 显示当前升/降序，重新查询 | query 保存排序 | 正式列表实现；原型未模拟服务端排序 |
| 页码 / 页大小 | 加载对应页 | query 保存；结果为空且页码超出时回末页 | 不把前端截断说成完整结果 |
| 行标题 | 跳该行详情 | 行内复选框和操作按钮不冒泡触发跳转 | 标题链接可新标签打开 |
| 表头复选框 | 仅选择当前页可操作行 | 明确显示“已选本页 N 条”；取消时清空本页 | 若未来支持全结果选择，必须二次明确范围 |
| 刷新 | 重新读取当前对象 / 列表 | 不清空筛选、表单或已选对象 | 提交中禁止触发冲突刷新 |
| 页签 | 跳独立子路径 | 刷新、复制链接、新标签均保持当前子页 | 不以组件内 `tabKey` 作为唯一路由 |
| 非交互统计 | 仅展示数字、口径、时间 | 不使用指针手势；可下钻时明确做链接 | 不制造伪按钮 |
| 保存 | 本地验证 → 提交 → 服务端确认 | 成功回详情；失败保留输入并聚焦错误 | 不用 toast 代替字段错误 |
| 取消 / 返回 | 无修改直接离开；有未保存修改提示 | “继续编辑”保留；“放弃修改”回来源 | 与业务删除确认不同 |
| 弹窗关闭 / Esc | 关闭短预览或未提交确认 | 焦点回打开按钮 | 确认正在提交时避免重复提交 |
| Toast | 展示可消失的成功回执 | 错误原因仍在页面持久可读 | 不能唯一承载失败恢复信息 |

## 1. 全局页面 G01–G06

### G01 登录 `/login`

| 元素 | 交互效果 | 校验 / 异常 |
|---|---|---|
| 邮箱 | 输入；回车提交表单 | 必填，合法邮箱格式；不先请求后端再提示空值 |
| 密码 | 输入；正式界面提供显示/隐藏且不改变值 | 必填，不记录到本地草稿 |
| 登录 | 调认证接口，成功跳有效 `returnTo`，否则 `/home` | loading、防重复；401 显示账号/密码不正确；5xx 显示服务异常 |
| 会话失效返回 | 重新认证后回原详情/编辑页 | 只允许站内路径，不能开放重定向 |
| 原型登录 | 任意合法邮箱、非空密码进入演示 | 明确不是真实认证；不保存密码 |

### G02 工作台 `/home`

| 元素 | 点击结果 | 状态规则 |
|---|---|---|
| 创建生产任务 | `/tasks/new?step=1` | 无任务也始终有此入口 |
| 继续上次工作 | 跳具体待办，如 `/datasets/24/samples?status=review` | 以真实 nextAction 为准，不固定跳任务总览 |
| 失败待办 | `/tasks/:id/runs/:runId` | 显示受影响数量、阶段和原因 |
| 清洗复查待办 | `/cleaning/:runId/findings?disposition=pending` | 完成复查后从待办移除 |
| 最近数据集名称 | `/datasets/:id` | 不再改变一个隐藏的全局 activeDataset |
| 最近评估 / 导出消息 | 对应报告 / 导出详情 | 已不可访问时给 404/403，不跳错对象 |
| 新手指导 | `/help/first-dataset` | 仅首次可强调，不阻挡已有用户 |

### G03 通知、G04 账户、G05–06 帮助

| 页 / 元素 | 点击结果 | 边界 |
|---|---|---|
| 通知标题 | 对象详情、失败运行或报告 | 同时标记该条已读；失败不阻止打开对象 |
| 全部标为已读 | 原页更新未读状态和角标 | 持久化通知为增量；首版可只提供运行列表链接 |
| 账户资料 | 显示姓名、身份、时区 | 无修改接口前只读，不能用可编辑样式 |
| 退出登录 | 调 logout，成功清本地会话并到 `/login` | 未保存表单先提示；失败保留明确状态 |
| 帮助文章卡 | `/help/:articleId` | 文章内步骤链接进入相关页 |
| 术语引用 | 文章锚点 | 解释 SFT/GRPO/方向/思维标准/裁判，避免模糊“结果” |

## 2. 数据集 D01–D07

### D01 列表、D02 概览

| 元素 | 点击结果 | 数据 / 异常 |
|---|---|---|
| 新建数据 | 通过“创建生产任务”进入 `/tasks/new` | 本版不额外引入外部数据导入模块 |
| 数据集名称 / 查看 | `/datasets/:id` | 现有 Dataset 读取接口 |
| 类型/状态筛选 | 限定 SFT / GRPO / 质量状态 | 正式版请求参数化；原型本地过滤 |
| 样本页签 | `/datasets/:id/samples` | 进入内容列表，不触发生成 |
| 待复查统计 | `/datasets/:id/samples?status=review` | 计数与筛选使用同一谓词 |
| 来源任务 | `/tasks/:taskId` | 第一阶段 taskId=datasetId；解耦后用真实关联 |
| 新建评估 | `/evaluations/new?datasetId=:id` | 预填数据集，校验当前产物可评 |
| 新建清洗 | `/cleaning/new?datasetId=:id` | 预填可检查阶段 |
| 创建导出 | `/datasets/:id/exports/new` | 前置内容不齐备时说明并指向缺失项 |
| 最近评估 / 清洗报告 | 各自 runId 详情 | 不借“当前选中运行”恢复上下文 |

### D03 样本列表、D04 样本详情

| 元素 | 点击结果 | 空 / 失败 / 状态变化 |
|---|---|---|
| 问题标题 | `/datasets/:id/samples/:sampleId` | sampleId 稳定；父子归属校验 |
| 类型、方向、质量筛选 | 更新当前范围 | query 与结果数一致；无结果可清空 |
| 行复选框 | 显示批量栏及 N 条选择 | 翻页后是否保留由显式模式决定；首版仅当前页 |
| 导出选中项 | 导出创建页预填 sampleIds | 服务端校验授权、完整性并冻结集合；增量 |
| 导出当前范围 | 导出创建页预填过滤条件 | 预览和执行需要快照保证一致；增量 |
| 上一条 / 下一条 | 在来时筛选结果中移动 | 无邻项则禁用；刷新详情后仍可由 query 恢复范围 |
| 复制内容 | 复制当前样本完整内容 | 不复制其它样本；clipboard 不可用时可手选复制 |
| 评分证据 | `/evaluations/:runId/items/:itemId` | 无评估显示“尚未评估”并提供新建入口 |
| 思维标准版本 | 对应标准与固定版本 | 当前标准有版本表；样本引用版本的完整关联需补 |
| 清洗命中 | `/cleaning/:runId/findings/:findingId` | 显示命中上下文和处置，不直接删除样本 |
| 原始内容 | 问题 → 思维链 → 答案，按段浏览 | 长文本分页/懒加载；错误区独立重试 |

样本默认只读。本方案没有假设已有任意修改训练样本、人工重写答案的后端能力。

### D05 导出列表、D06 创建、D07 详情

| 元素 | 点击结果 | 校验 / 依赖 |
|---|---|---|
| 文件标题 | `/datasets/:id/exports/:exportId` | 展示该次配置与产物，不以“最新文件”代替 |
| 创建导出 | `/datasets/:id/exports/new` | 现有格式和 mappings 来自 `/export/formats` |
| 范围 | 已通过 / 当前过滤 / 已选样本 | 后两者需要样本集合快照；不可选择 0 条 |
| 格式 | 选择后更新字段预览与兼容映射 | 以服务端支持格式为准；当前已注册 JSONL / CSV / Parquet / Alpaca / ShareGPT |
| 映射 | 仅列适用于训练类型与格式的映射 | 缺必需字段/重复目标键，阻止提交 |
| 查看映射 | 打开导出页内只读映射快照；管理员另可从资源库管理 `/resources/mappings/:id` | 成员数据来源为数据集 `/export/formats`，不调用 admin GET；关闭后保持草稿 |
| 创建导出文件 | 提交后跳导出运行详情 | 入队不等于就绪；下载只有产物实际存在后启用 |
| 下载 | 请求该 artifact ID 对应文件 | 失败留在详情，可重试；历史存储变更不改原 bucket |
| 复制链接 | 复制详情 URL | 不复制临时签名 URL；鉴权仍由服务端处理 |
| 导出失败 | 显示错误与范围，允许时重试 | 需补独立 export run/config snapshot；首版映射 generation-run + artifact |

## 3. 生产任务 T01–T11

### T01 列表与 T02 三步创建

| 步骤 / 元素 | 行为 | 校验 / 默认值 / 结果 |
|---|---|---|
| 列表任务名 | `/tasks/:id` | 进度列展示当前阶段的分子/分母 |
| 任务状态筛选 | 进行中 / 待确认 / 部分失败 / 已完成 | 未知后端状态显示“状态待确认”，不猜成功 |
| 新建 | `/tasks/new?step=1` | 明确独立页面，可刷新恢复非敏感草稿 |
| 1：任务名称 | 可编辑 | 业务建议必填、1–80 字；正式后端同步校验 |
| 1：主题与范围 | 多行输入 | 必填、1–2,000 字；说明业务边界 |
| 1：SFT / GRPO | 单选卡 | 默认 SFT；切 GRPO 展示奖励档位；已有输入保留 |
| 1：奖励档位 | 数值列表 | GRPO 必填；至少 2 个互异有限数，去空格、排序预览；非法值就地报错 |
| 1：从模板开始 | `/resources/templates` | 选择模板后将配置复制进草稿，不绑定将来变更 |
| 2：n/m/x | 正整数输入，实时乘积预览 | ≥1；上限来自服务端容量策略；原型单项上限 1000 仅为表单保护，不是生产容量承诺 |
| 2：规模差异 | 显示问题总数 n×m×x | 不把 answerVariants/rewardVariants 乘后当问题数；与 targetSize 冲突需明确解释 |
| 2：执行方式 | 自动执行 / 逐步执行 | 自动模式能力未上线前不让真实用户选中；原型展示目标态 |
| 3：就绪检查 | 展示模型、存储、模板和生产范围 | 后端预检待补；未就绪能到对应管理详情，成员看到可读说明 |
| 3：耗时/费用 | 无可靠模型时显示“暂无法估算” | 不阻止保存草稿，不造价格与倒计时 |
| 上一步 | 保存本地非敏感草稿，回 step−1 | 不重置前面输入 |
| 下一步 | 当前步骤验证通过才进入 step+1 | 聚焦第一个错误，顶部给错误摘要 |
| 创建并规划 | 创建对象并进入 `/tasks/:id` | 原子创建/入队为后端增量；首版分别创建与显式生成，失败保留已创建任务 |
| 取消 | 回任务列表 | 有实际更改时说明放弃草稿；不删除已存在任务 |

### T03 总览、T04 领域与方向

| 元素 | 点击结果 | 校验 / 状态 |
|---|---|---|
| 总览当前主动作 | 待确认→结构；失败→运行详情；完成→数据集 | 由明确状态/前置条件得出，不固定一条长 CTA |
| 阶段节点 | 同 taskId 的对应路径 | 未就绪也可查看原因；不能绕过后端启动守卫 |
| 查看数据集 | `/datasets/:datasetId` | 与任务执行视图区分 |
| 领域树节点 | 右侧编辑所选领域及其方向 | nodeId 进入 query；切换有未保存内容则提示 |
| 树搜索 | 过滤匹配领域/方向并保留父层级 | 不修改结构本身 |
| 新增领域 | 简短名称弹窗→新节点草稿 | 同级名称不能空或重复 |
| 新增方向 | 添加当前领域的方向行 | 自动聚焦名称；至少一个方向才能确认领域 |
| 移除方向 | 从草稿移除，可通过取消恢复 | 已产生下游内容时不能直接删除；需变更影响流程，第二阶段提供版本分支 |
| 保存结构 | 保存当前完整结构 | 校验空名、重名、孤立方向；错误定位到节点 |
| 重新生成 | 先说明是否覆盖草稿与影响 | 默认仅在无下游产物的规划期可用；运行中禁用 |
| 确认并继续 | 校验保存状态→确认→进入标准页 | 确认按钮不暗中发起不可追踪的多个前端请求 |

### T05–06 思维标准

| 元素 | 点击结果 | 校验 / 状态 |
|---|---|---|
| 标准列表方向名 / 编辑 | `/tasks/:id/standards/:directionId` | 单独地址，适合长表单 |
| 生成缺失标准 | 显示方向范围→提交生成→运行可见 | 精确“缺失”范围计算以服务端为准；已存在内容默认保留 |
| 步骤标题 / 描述 / 检查点 | 编辑该版本草稿 | 标题和步骤要求必填；后端同步验证 |
| 添加 / 移除 | 修改草稿步骤集合 | 至少 1 步，删除未提交步骤可撤销 |
| 上移 / 下移 / 拖动 | 调整步骤次序 | 自动重编号；键盘也能完成，不能只能拖拽 |
| 版本历史 | 只读版本选择和对比 | 现有版本接口；恢复旧版应新建版本，不覆盖历史 |
| 变更说明 | 记录修改原因 | 保存新版本时必填 |
| 保存为新版本 | PUT 标准→成功显示版本号 | 并发版本冲突待后端补 409/版本校验，不能最后写入静默覆盖 |
| 下一步：问题集 | `/tasks/:id/questions` | 保留 taskId；不要求返回任务总览 |

### T07 问题集、T08 训练产物、T11 历史评分

| 元素 | 点击结果 | 校验 / 状态 |
|---|---|---|
| 难度统计 | 展示简单/中等/困难的数量与比重 | 统计分母为问题数；与实际接口层级一致 |
| 生成问题 | 配置每方向 x、难度分布后提交 | 前置领域/方向与标准按契约验证；比例总和为 100% |
| 问题行 | 进入完整样本 / 问题详情 | 尚无训练产物时只显示问题，明确后续内容未生成 |
| 下一步：训练产物 | 同任务 `/output` | 根据 task targetKind 呈现 SFT 或 GRPO |
| SFT 生成 | 思维链 + 可选答案配置→入队 | 不能误调用历史 reasoning 分支代替新 SFT 记录 |
| GRPO 生成 | 奖励档位检查→教师提示词生成 | 显示提示词、各档判断与框架引用 |
| 调整奖励档位 | 编辑草稿，确认后生成新产物版本 | 旧产物与导出不被覆盖；增量版本契约 |
| 复制教师提示词 | 复制当前问题关联的完整提示词 | 不用当前页第一段文字代替完整产物 |
| 查看数据集 | `/datasets/:id` | 默认样本视图定位对应训练类型 |
| 历史自动评分 | `/tasks/:id/scoring` | 读取 rewards；标题明确“历史流程”，不再同名“质量评估” |

### T09–10 运行记录与失败恢复

| 元素 | 点击结果 | 校验 / 状态 |
|---|---|---|
| 运行编号 | `/tasks/:id/runs/:runId` | 精确指定阶段的一次运行 |
| 原因与影响 | 持久显示错误摘要、失败范围、时间 | 不泄漏服务密钥或数据库错误 |
| 仅重试失败部分 | 展示失败数量→确认→原 run 续跑或关联新尝试 | 同阶段幂等，已成功结果保留；当前 resume 按 stage，细粒度清单需补 |
| 模型检查 | 管理员进入具体 provider 详情 | 普通成员进入恢复指引，不给无权访问按钮 |
| 刷新 | 读取运行最新状态 | running / queued 定时轮询，结束停止；后台轮询降频 |
| 返回运行列表 | 保留任务和筛选 | 新尝试就绪后仍能看旧错误记录 |

## 4. 质量评估 E01–E06

| 页 / 元素 | 点击结果 | 校验 / 异常 |
|---|---|---|
| E01 评估名称 | `/evaluations/:runId` | 列表默认展示最新运行，而不是维度配置 |
| E01 查看报告 | `/evaluations/:runId/report` | 运行中变为“查看进度”，未完成不显示最终结论 |
| E01 维度库 | `/resources/dimensions` | 独立配置域 |
| E02 数据集 | 加载可用产物、样本数与候选裁判 | 切数据集清除不兼容维度/裁判，说明被移除项 |

## 6. 资源库 R01–R14 与共享新增/编辑表单

R01 只做 6 类资源的目录与说明。每个资源列表只管理一个对象；新建/详情/编辑均独立地址。普通成员只能获得真实接口允许的操作，不因换了菜单就扩大权限。

| 资源 | 列表 → 详情 / 编辑 | 表单元素与验证 | 特有交互 |
|---|---|---|---|
| R02–03 生成模板 | `/resources/templates` → `/:id` → `?mode=edit` | 名称、训练类型、n/m/x、生成偏好；正整数、规模上限；与旧 strategy 字段做明确映射 | “使用模板”复制到创建草稿；不修改共享模板 |
| R04–05 评估维度 | `/resources/dimensions` → `/:id` | 名称、唯一 key、分类、描述、rubric、min/max、weight；min<max，weight>0 | 内置只读可停用；“复制为自定义”进入预填新表单，key 必须修改；删除仅自定义并校验引用 |
| R06–07 清洗规则 | `/resources/rules` → `/:id` | 名称、多选阶段、minHits≥1、优先级、动作、启用；具体词配置关联 | 停用只影响新运行；打开“用此规则新建清洗”预填 ruleId |
| R08–09 关键词 | `/resources/keywords` → `/:id` | 匹配文本、contains/prefix/regex、类别、严重级别、说明、启用 | regex 编译校验，空模式拒绝；删除有影响说明，历史报告保留文本快照 |
| R10 关键词导入 | `/resources/keywords/import` | 文本/文件逐行解析、类别/级别；去空行、重复预览、错误行定位 | “解析预览”不提交；“导入”返回新增/跳过/错误数；错误项可修正再次导入 |
| R11–12 生成指令 | `/resources/prompts` → `/:id` | 名称、阶段、版本、系统/用户指令；占位符允许列表、必需变量 | 保存不自动影响运行中任务；版本化执行快照需补 |

共享行为：点击新建进入 `/new` 空表单；点击编辑进入 `/:id?mode=edit`；保存验证后回详情；取消回来源；停用说明后更新状态；保存错误保留草稿。无后端删除能力的资源不展示删除按钮。资源权限须按现有 API 分组：策略、指令、映射是 admin API；评估/清洗资源目前是已登录域，不假设已存在细粒度角色。

## 9. 原型范围的明确说明

原型已实现：64 个目录页面的实际 hash 跳转；新建/编辑视图；SFT/GRPO 条件字段；三步向导草稿；本地搜索/筛选与选择；短操作确认；步骤编辑；续跑回执；评分与清洗上下文；本地演示下载；7 类页面场景和成员/管理员切换。

原型没有连接生产 API、真实调用模型、真实写存储、发送通知、实现数据库版本快照、服务器分页或后台编排。列表行是少量静态样例，部分“生成/测试”动作只演示确认与回执；完整真实执行由后续实施计划负责。所有页面的底部持续显示“交互原型 / 演示数据”，评审工具不是正式产品界面的一部分。

本文描述的服务端检索、未保存拦截、返回滚动恢复、细粒度资源校验、版本冲突和完整键盘无障碍是实施验收要求；不能因为静态原型能点击就判定生产能力完成。
