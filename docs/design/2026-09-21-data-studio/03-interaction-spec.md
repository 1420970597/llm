# Atelier 交互规格

本文把“一个元素点下去会发生什么”写成可以验收的契约。路径使用原型 Hash URL；正式产品将对应真实路由。所有表单都有浏览器校验、服务端再次校验、成功反馈和失败保留草稿。

## 0. 全局交互契约

| 元素 | 点击/键盘效果 | 成功状态 | 失败与返回 |
|---|---|---|---|
| 品牌 `a.` | 回到 `/today` | 今日工作上下文 | 当前脏表单先出现离开确认 |
| 今日/项目/方案库/交付库 | 切换全局入口 | URL 改变，页面标题和选中态同步 | 脏表单弹窗：放弃或继续编辑 |
| 项目顶部六个标签 | 在同一项目内切换 | 保留项目名、训练类型和当前对象上下文 | 无权限时显示拒绝状态 |
| 搜索按钮 / `Ctrl⌘K` | 打开命令搜索；输入过滤 8 条页面/对象 | 回车或点击结果跳转，`Esc` 关闭并恢复焦点 | 无结果显示“没有匹配页面” |
| 底部身份 | 选择项目负责人/只读访客并重新渲染 | 验证权限呈现，不代表真正授权 | 访客隐藏设置，所有变更控件禁用 |
| 底部场景 | 切换正常、空数据、加载、失败、断网、无权限、不存在 | 保持当前 URL，显示对应状态 | 失败/断网提供重新连接；其它状态提供返回 |
| 表单文本/选择 | 输入即标记未保存 | 离开显示脏状态确认；提交才写入 | 原值保留，聚焦首个无效字段，显示可理解错误 |
| 页面返回 | 浏览器返回回到上一个 URL 和筛选参数 | 项目上下文不丢失 | 已保存对象不会被撤销；需要撤销要创建新版本 |
| 状态 badge | 仅表达事实，不作为唯一入口 | 颜色、文字、辅助文本一致 | 禁止用颜色单独表达成功/失败 |

“返回”永远返回上一级工作对象；“取消”返回而不写入；“创建新版本”复制当前内容并保留旧版本；“重置演示”只清除本地原型状态。

## 1. 工作区与项目启动

### 今日工作 `/today`

| 元素 | 点击后 | 目的/校验 |
|---|---|---|
| `＋ 开始一个数据项目` | `/new` 三步启动向导 | 不立即发起模型调用 |
| `浏览生产方案` | `/recipes` | 选择完整方法而非单个 Prompt |
| “进入审阅” | Aurora `/data/s104` | 直接打开待处理样本 |
| “比较试制” | Aurora `/compare` | 进入相同基准 A/B 证据 |
| “查看全部” | `/projects` | 项目搜索和卡片 |
| 项目卡 | `/p/{id}/overview` | 带入项目上下文 |
| “查看发布候选” | `/p/aurora/releases/v1.2` | 显示阻塞原因和冻结前清单 |
| “了解完整流程” | `/help` | 不改变项目状态 |

### 新建项目 `/new`、`/new/coverage`、`/new/quality`

三步向导始终显示步骤圆点和退出入口。第一步输入名称、交付目标并二选一 SFT/GRPO；第二步输入 `n × m × x` 和首次试制数，实时计算目标问题数；第三步输入接纳率、预算和预算达到后的策略。每一步的“下一步”先执行 required、范围和整数校验，失败时停留当前页；“上一步”恢复已输入草稿。

最后一步“创建项目并设计方案”写入项目草稿，进入 `/p/aurora/blueprint` 或 `/p/boreal/blueprint`。旁侧“你将得到”只说明对象和不调用模型的事实。预算数字在原型中明确是虚构规划值。

### 项目列表 `/projects`

搜索框只过滤卡片名称和目标；空结果显示可操作提示。项目卡的整块区域和标题都可点击，方案入口进入 `/recipes`。列表不在卡片内塞入“立即生产”等高风险动作，防止误触。

## 2. 设计工作区

### 生产蓝图 `/p/{project}/blueprint`

左侧画布按固定顺序显示覆盖范围 → 思维标准 → 生成 → 独立评估/规则检查 → 人工检查点 → 版本交付。每个节点是可聚焦链接，点击后通过 `?node=...` 保持画布位置并更新右侧检查器；键盘 Tab 顺序与视觉顺序一致。分支不是任意代码画布，普通用户不需要拖拽编程。

右侧检查器包含执行模式、并发上限和步骤说明。点击“保存为新方案版本”创建 blueprint 新版本，显示 toast，并明确已有批次保持配置快照；无效并发数（<1、>32、非数字）停留当前页。三个文本链接分别进入覆盖矩阵、思维标准、清洗策略。

### 覆盖矩阵 `/coverage`

矩阵单元显示领域、方向、已覆盖/缺口和计数。右侧“下一批覆盖计划”填写方向、补充问题数和优先难度；保存只影响下一批。缺口单元为只读数据，右侧表单可规划补充，已通过内容不会被重做。

### 思维标准 `/standard`

多行文本每行代表一个检查步骤；变更说明必填。点击“保存新版本”去掉空行、创建 `standard_version + 1`，保留在标准页并说明历史执行不变。空步骤、缺少变更说明或只有不可验证的“认真思考”提示时应给出具体校验建议。

### 小批试制 `/pilot`

填写试制数量（1–100）、覆盖方式和方案版本；“启动试制”创建独立 P03，而不是修改主生产批次。旁侧显示模型调用按实际计量、计划样本、预算和未知费用。提交后进入 `/runs/p03`，状态为排队，原型不模拟生成成功；可从该页查看历史 P01/P02 的固定 A/B 示例。

### 试制对比 `/compare`

A/B 两栏固定显示相同基准、方案版本、通过数、各质量维度、异常解释和示例成本。按钮“采用方案 B 并规划扩量”先打开确认弹窗，说明目标规模、预算和真实执行前置条件；确认后进入批次规划。对比页面不提供自动发布按钮。

## 3. 生产和数据工作区

### 生产批次 `/runs`

### 扩量规划 `/runs/new` 与新批次 `/runs/b19`

从 A/B 采用按钮或批次列表进入规划，选择方案 A/B、覆盖范围、目标数量（1–100,000）、预算上限（至少 1 元）。创建后冻结为 B19；返回新批次详情显示排队、计划和 0 实际产出。B18 的成功/失败记录保持独立。原型固定演示一个 B19；真实系统每次提交分配新 ID，编辑已提交计划必须产生新批次。

表格行点击进入批次详情。P03 明确为试制，B18 明确为主生产；每行只放与该批次相关的“详情/对比”。表头固定表达范围、方案快照、状态和实际产出，禁止用“最新”替代批次 ID。

### 批次详情 `/runs/b18`

“暂停后续请求/继续执行”是可逆动作，确认后更新事件时间线；暂停不撤回在途请求。统计显示阶段、已完成、失败和示意费用。配置快照可展开查看模型、标准、规则和停止条件；“查看异常”进入失败列表。

### 异常 `/runs/b18/failures`

表格列出幂等条目、阶段、错误和已成功内容。“恢复失败项”弹出说明：沿用同一快照、保留成功内容、不会清空历史。访客无权恢复；恢复后按钮禁用并显示请求已提交。

### 样本工作区 `/data`

搜索支持样本标题或 ID；状态下拉支持全部、待审阅、已接纳、已隔离；筛选条件写入 URL，可复制和返回。行 checkbox 只选择当前可见样本；“导出所选”无选择时给 toast，有选择时进入带 `selection=` 的发布准备。样本标题和“审阅”都进入三栏审阅。审阅入口默认只显示待审阅队列，显式改变状态筛选后允许检查其它处置。

### 三栏审阅 `/data/s104`

左栏队列点击切换样本；中栏内容、问题、推理/教师提示词和答案只读；“版本与来源”进入历史；“复制内容”优先使用剪贴板，失败则打开只读文本框。右栏显示规则命中和多裁判证据，并提供“查看策略/完整评估”。底部表单选择已接纳或已隔离，判断依据必填；保存只写入 Decision，不改原始文本并刷新队列状态。

“专注内容”隐藏左右两栏；按钮文案变为“显示队列与证据”。`Esc` 关闭任何弹窗并恢复触发控件焦点。GRPO 样本将中栏标签切换为教师提示词、奖励判据，字段结构不退化为 SFT。

### 样本历史 `/data/s104/history`

时间线按人工判断、质量实验、内容版本和来源批次排序。所有条目可跳转到对应实验或批次；追溯对象列出项目、样本、内容、标准和批次 ID。原始内容没有“编辑”按钮，改进动作从新标准/新批次开始。

## 4. 质量工作区

### 实验室 `/quality`

风险切片按同一量表显示覆盖；“进入审阅”打开待判断队列；“新建质量实验”进入配置；当前实验卡进入 E9 报告；清洗策略进入 `/rules`。数字必须写清分母和抽样范围，不把不同分母的百分比相加。

### 新建实验 `/quality/new`

填写名称、目标内容、抽样方式和数量/比例；至少选择一个独立裁判。Atlas（生成模型）不能作为自评裁判。选择“按比例”时输入不得超过 100；点击创建后状态先为排队，不展示最终质量结论。GRPO 目标显示教师提示词与奖励判据，旁侧说明档位覆盖的专属检查。

### 实验报告 `/quality/e9`

排队期间显示范围、裁判和未就绪的报告；约 2 秒后原型转为完成。完成页说明抽样结论边界、维度、低分和分歧数量，并通过证据卡进入样本。分歧不是自动隔离指令。

### 清洗策略 `/rules`

输入名称、匹配表达式、匹配方式和命中动作。“预览当前样例”只计算命中并展示跳转，绝不修改数据；正则语法错误即时 toast。保存策略创建新版本，仅影响后续实验；历史命中保留表达式和匹配位置。

## 5. 发布和辅助工作区

### 发布版本 `/releases`

卡片显示候选/已发布、固定样本数和数据卡入口；“准备新版本”复制当前项目状态为新的候选。交付库入口只查看跨项目版本。

### 发布准备 `/releases/new`

填写 `v数字.数字` 版本名、样本范围、格式和用途限制。若从样本表进入，范围下拉锁定为已勾选样本。提交后进入数据卡候选，不直接下载。SFT 支持 JSONL/Alpaca/CSV；GRPO 只显示 JSONL，并预览专属字段。

### 数据卡 `/releases/v1.2`

候选页逐条显示结构匹配、待审阅归零、内容/策略/映射版本。待审阅条目提供直接样本链接；“冻结并发布”在有未处理条目时弹窗引导回证据或缩小范围。发布确认记录样本 ID、蓝图/标准/策略版本、映射、用途和时间。发布后只显示“下载训练文件”和“创建下一版本”，清单不再随项目变化。

### 下载与交付库

下载使用固定 release ID 和快照记录生成文件；原型生成少量本地演示记录并通过 toast 说明数量。交付库默认展示已发布版本，候选状态必须有明确标识。文件名包含训练类型和版本，不使用 `latest`。

### 动态、设置、帮助、目录

动态的每条卡片都有对象链接；“全部标为已读”只改阅读状态。设置连接页的测试与保存分离，API 密钥不回显/不存原型；成员页显示角色能力而非随意开关。帮助页给出推荐旅程和快捷键。全站目录列出 39 个主要画面，用于评审而非产品主入口。

## 6. 响应式与可访问性

桌面三栏在 1150px 以下先把证据放到下一行，760px 以下全部堆叠；导航可局部横滑，表格保留横向滚动，不压缩正文。

## 7. 生产蓝图各节点的正式产品配置契约

原型的节点检查器演示通用模式、并发和说明，以及独立详情入口。正式实现应按以下字段展开，不能把所有节点做成同一表单。以下为目标设计，未假装已经接入可执行服务。

| 节点 | 控件与默认值 | 点击/修改效果及约束 |
|---|---|---|
| 覆盖范围 | 领域列表、方向列表、难度配比、每方向配额、来源选择 | 添加/删除只改草稿；删除已被运行引用的方向时仅从下一版移除；配比和必须为 100%，缺口入口定位该切片 |
| 思维标准 | 标准版本选择、步骤列表、每步检查点、“插入步骤/上移/下移” | 修改生成标准草稿，保存附变更理由；预览只展示格式，不启动模型；历史版本只读、可复制 |
| SFT 生成 | 连接选择、模型版本、温度 0–2、输出上限、JSON Schema、失败策略 | 模型切换提示采样参数兼容性；“验证结构”运行 schema 校验；必需 question/reasoning/answer；缺密钥跳到连接设置后返回本节点 |
| GRPO 生成 | 教师提示词模板、档位编辑器、各档规则、边界例、证据引用要求 | 档位不得重复，至少 2 档，每档至少 1 判据；预览三档示例回答的预期判断；保存质量适配器标识 |
| 独立评估 | 裁判多选、抽样方式/seed、维度量表、权重、缺分策略 | 相同真实模型来源提示不独立；权重和=1；“试评”创建独立小实验，不能覆盖正式结果；按统一量表再聚合 |
| 规则检查 | 规则名、包含/正则/字段完整性/结构检查、字段范围、严重度、命中动作 | 正则本地校验，服务端限制执行时间；预览高亮实际位置；默认入审阅；“删除规则”仅影响下一策略版本 |
| 人工检查点 | 风险范围、分派人、处置选项、理由必填开关、抽检比例 | 队列按样本版本合并重复风险；分派不修改内容；多审阅者冲突保留两条判断并进入待协调状态 |
| 版本交付 | 必需质量门槛、字段映射、格式、数据卡、发布范围 | “校验映射”展示 3 条预览、缺字段定位节点；范围写入候选 manifest；阻塞项点击精确返回证据；发布冻结所有引用 |

## 8. 原型与目标态的明确边界

本文的服务端冲突、自动同步和完整历史是实施契约。原型只在同一标签页 sessionStorage 保存演示状态；项目创建复用两套样例容器；实验报告由冻结的 1–3 条演示内容派生，不包含真实裁判响应；标准/节点保存保留最新演示版本号，未实现完整历史版本浏览；成员与存储配置为只读说明，没有发送邀请或切换存储的按钮。应用内链接离开有确认，浏览器刷新有 beforeunload 提示；浏览器后退对未保存字段的拦截尚待路由工程阶段实现。只读角色与状态切换仅为评审工具。

桌面三栏审阅在窄屏变成上下流：队列可横向滚动，中栏全文，证据在下方；蓝图节点堆叠，右侧检查器下移。所有主要操作既可点击也可用 Tab/Enter；页面切换后焦点移动到标题；状态有文字；弹窗支持 `Esc` 和焦点返回；表格可横向滚动而不压缩关键字段。
